## Описание модулей
1. ### masks. Модуль имеет 2 функции:
- #### get_mask_card_number - Функция получения номера карты владельца и выдача его с маской;
- #### get_mask_account - Функция получения счета карты владельца и выдача его с маской.
2. ### widget. Модуль имеет 2 функции:
- #### mask_account_card - Функция приема строки с номером карты или счетом владельца и выдача его с соответствующей маской;
- #### get_date - Функция выделения даты из временного события.
3. ### processing. Модуль имеет 2 функции:
- #### filter_by_state - Функция принимает список операций по карте и возвращает новый список выполненных операций, с заданным состоянием
- #### sort_by_date - Функция принимает список операций по карте и возвращает список с сортировкой по дате
4. ### generators. Модуль имеет 3 функции:
- #### filter_by_currency - Функция принимает на вход список словарей, представляющих транзакции и возвращает итератор транзакций, где валюта операций соответствует заданной; 
- #### transaction_descriptions - Функция принимает на вход список словарей, представляющих транзакции и возвращает описание каждой операции по очереди; 
- #### card_number_generator - Функция генератор, который выдает номера банковских карт.
5. ### decorators. Модуль имеет 1 функцию:
- #### log - который будет автоматически сохранять в лог начало и конец выполнения функции, а также ее результаты или возникшие ошибки. Если не задано имя файла, логи выводятся в консоль.
